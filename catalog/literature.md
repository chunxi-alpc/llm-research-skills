# 文献检索与引文核对

[返回分类总览](README.md) · [Skills 下载](../downloads/README.md)

先说明主题和发表范围，再核对论文入口。已有一组论文时，可转到论文阅读页做对比。

| 编号 | 资料 | 如何使用 |
|---|---|---|
| R001 | [NotebookLM：多论文比较](entries/R001.md) | 上传或选择待比较论文，再提出跨论文对比与研究问题。 |
| R002 | [Gemini / ChatGPT：按条件找论文](entries/R002.md) | 给出研究领域、方向、年份与会议条件，再核对返回论文的正式入口。 |
| R003 | [RefCheck.ai：BibTeX 引文检查](entries/R003.md) | 按项目说明上传或粘贴 BibTeX，查看不匹配字段和推荐匹配结果。 |
| R004 | [Wispaper：关键词文献检索](entries/R004.md) | 输入关键词，再按相关度、年份和出处筛选；区分预印本与正式版本。 |
| R005 | [AMiner：学术检索与研究趋势](entries/R005.md) | 先在网站检索主题；需要 Agent 接入时，再按官方提供的技能或接口配置。 |
