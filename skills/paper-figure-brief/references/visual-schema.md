# 绘图说明模板

按方法实际内容填写，删去不适用的项。模块和箭头必须对应输入材料。

```text
[VISUAL SCHEMA]
图的目的：希望读者看懂的一个核心关系。
版面：单栏或双栏，宽高比，阅读方向。
阶段与分组：例如训练与推理；注明哪些模块共享。
模块表：模块名称、功能、输入、输出、位置、图内标签。
连接表：起点 → 终点；传递内容；实线或虚线及其含义。
重点：论文新提出的部分，以及用何种方式突出。
视觉要求：背景、颜色用途、字体层级、对齐和留白。
图内文字：列出需要准确出现的英文或中文标签。
图注：解释流程和缩写，不新增论文主张。
待核对：原文未说明的关系、容易混淆的箭头和标签。
```

绘图提示词应将上述信息合成一段完整说明。复杂流程可附连接表，避免让绘图模型自行推断算法。
