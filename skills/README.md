# 本表制作的 10 个 Skills

这是本仓库根据原表制作的技能，与 third_party 中的原项目文件分开保存。每个技能包含 SKILL.md、来源说明及必要参考文件。

[下载与使用](../downloads/README.md) · [原始提示词](../prompts/original-prompts.md)

| 技能 | 适用任务 | 单个包 |
|---|---|---|
| [文献检索](research-literature-search/SKILL.md) | 按领域、会议和年份找论文，下载并整理检索结果。 | [下载](../downloads/individual/research-literature-search.zip) |
| [论文阅读与多论文对比](research-paper-reading/SKILL.md) | 精读或比较论文，查找原文依据，讨论优缺点和后续研究方向。 | [下载](../downloads/individual/research-paper-reading.zip) |
| [学术语言润色](academic-language-polish/SKILL.md) | 润色英文学术段落，理清句间逻辑并保持术语一致。 | [下载](../downloads/individual/academic-language-polish.zip) |
| [方法逻辑与术语一致性检查](method-logic-check/SKILL.md) | 根据已有定义统一术语和符号，检查方法描述中的逻辑问题。 | [下载](../downloads/individual/method-logic-check.zip) |

| [拼写与语法纠错](academic-proofreading/SKILL.md) | 修正论文的拼写、语法、句法、时态和单复数错误，保留其余表达。 | [下载](../downloads/individual/academic-proofreading.zip) |
| [学术翻译（中译英）](academic-translation/SKILL.md) | 保留原意和英文术语进行中译英，或生成适合 Word 的英文稿和中文直译。 | [下载](../downloads/individual/academic-translation.zip) |
| [编程任务需求整理](coding-task-brief/SKILL.md) | 结合项目文件说明编程需求、拆解任务或按六项信息组织指令。 | [下载](../downloads/individual/coding-task-brief.zip) |
