# 计算机科研：数学理论、算法技术与方法设计思想总目录

范围：
整合前文与附件中的方法性内容，并补充本轮发现的缺漏。

收录：
数学理论、统计建模、理论分析工具、优化算法、学习方法、
损失函数、网络结构、推理机制、数据结构、系统机制、方法设计思想。

不单独收录：
常规实验流程、数据划分规范、评测指标清单、基准数据集清单、
随机种子管理、环境配置、论文汇报与复现管理。

分类说明：
基础理论、方法族、具体算法、代表性模型不是同一层级；
代表性模型放在其对应的方法类别内。
目录覆盖本次合并与扩展的范围，不视为所有科研方法的封闭全集。

# 术语边界

模型蒸馏 ≠ 数据集蒸馏。
模型集成 ≠ 模型合并。
测试时计算扩展 ≠ 测试时适应 ≠ 测试时训练。
GFlowNet ≠ Normalizing Flow ≠ Flow Matching。
外部记忆淘汰 ≠ 参数化机器遗忘。
文本重建 ≠ 像素重建 ≠ 潜在空间预测。
正交性 ≠ 统计独立性 ≠ 语义解耦。
状态估计 ≠ 文本摘要 ≠ 显式贝叶斯滤波。
因果推断 ≠ 输入干预 ≠ 模型归因。
Crosscoder ≠ 跨层 Transcoder。
概率 ≠ 模糊隶属度 ≠ 可能性 ≠ 证据信任度。
误差理论分析 ≠ 实验误差统计。
自动化测试生成算法 ≠ 论文中的常规测试流程。
理论工具、方法族、具体算法、网络结构、系统机制可以组合，但不能仅凭名称相近就视为同一种技术。
